# LTC6813 官方库功能说明

基于本工程中的 Analog Devices / Linduino 移植：

| 层级 | 文件 | 角色 |
|------|------|------|
| 芯片封装 | `LTC6813_stm32.c/.h` | 应用层应优先调用 |
| 通用底层 | `LTC681x.c/.h` | 命令、PEC、算法实现 |
| 硬件抽象 | `bms_hardware.c/.h` | SPI / CS / 延时 |

应用侧一般只调 **`LTC6813_*`** 与 **`wakeup_*`**；`LTC6813_*` 多数直接转调 `LTC681x_*`。

---

## 一、库能实现的功能总览

1. **通信与唤醒**：把 daisy-chain 从 sleep/idle 唤醒，维持 isoSPI 通信  
2. **配置管理**：读写 CFGRA/CFGRB（基准、GPIO、放电、UV/OV 等）  
3. **电芯电压测量**：启动 ADC、等待完成、读回并解析  
4. **GPIO / 温度测量**：AUX 转换与读回（NTC 等接 GPIO）  
5. **状态量测量**：SOC、内部温度、稳压等 STAT 通道  
6. **被动均衡**：DCC 放电位、PWM、S 控制脉冲  
7. **断线诊断**：电芯开路、GPIO 开路  
8. **自检与冗余**：数字滤波自检、重叠测试、冗余 ADC  
9. **通信扩展**：COMM 口 I2C/SPI 透传  
10. **静音控制**：MUTE / UNMUTE（均衡相关）  
11. **PEC 校验统计**：通信完整性检查

## 二、按功能分类的函数

### 1. 硬件与底层通信（`bms_hardware` + `LTC681x`）

| 函数 | 功能 |
|------|------|
| `bms_hardware_init` | 初始化 CS、确保 SPI 就绪 |
| `cs_low` / `cs_high` | 片选 |
| `spi_write_array` / `spi_write_read` / `spi_read_byte` | SPI 收发 |
| `delay_u` / `delay_m` | 微秒/毫秒延时 |
| `wakeup_idle` | 从 IDLE 唤醒到 READY |
| `wakeup_sleep` | 从 SLEEP 唤醒 |
| `cmd_68` / `write_68` / `read_68` | 底层命令/写/读（含 daisy-chain） |
| `pec15_calc` | PEC15 校验计算 |

---

### 2. 初始化与配置寄存器

| 函数 | 功能 |
|------|------|
| `LTC6813_init_reg_limits` | 设置 6813 通道数等限制（18 cell / 9 aux 等） |
| `LTC6813_init_cfg` | 清空/初始化 CFGRA 软件镜像 |
| `LTC6813_init_cfgb` | 初始化 CFGRB 软件镜像 |
| `LTC6813_set_cfgr` | 一次设置 REFON、ADCOPT、GPIO1–5、DCC、DCTO、UV、OV |
| `LTC6813_set_cfgr_refon` | 基准保持开关 |
| `LTC6813_set_cfgr_adcopt` | ADC 选项位 |
| `LTC6813_set_cfgr_gpio` | GPIO1–5 配置（下拉开/关，作模拟输入时常置 1） |
| `LTC6813_set_cfgr_dis` | 放电位 DCC1–12 |
| `LTC6813_set_cfgr_dcto` | 放电超时 DCTO |
| `LTC6813_set_cfgr_uv` / `set_cfgr_ov` | 欠压/过压阈值 |
| `LTC6813_set_cfgrb` | 设置 CFGRB（FDRF、DTMEN、PS、GPIO6–9、DCC13–18 等） |
| `LTC6813_set_cfgrb_fdrf` | 强制数字冗余 |
| `LTC6813_set_cfgrb_dtmen` | 放电定时使能 |
| `LTC6813_set_cfgrb_ps` | 数字冗余路径选择 |
| `LTC6813_set_cfgrb_gpio_b` | GPIO6–9 |
| `LTC6813_set_cfgrb_dcc_b` | 高位电芯放电位 |
| `LTC6813_wrcfg` / `wrcfgb` | 将配置写入芯片 |
| `LTC6813_rdcfg` / `rdcfgb` | 读回配置并校验 PEC |

---

### 3. 电芯电压 ADC

| 函数 | 功能 |
|------|------|
| `LTC6813_adcv` | 启动电芯电压转换（`MD`/`DCP`/`CH`） |
| `LTC6813_adcvax` | 电芯 + GPIO1/2 联合转换 |
| `LTC6813_adcvsc` | 电芯 + 电芯总和（SOC）联合转换 |
| `LTC6813_adol` | 重叠测量（用于 overlap 自检） |
| `LTC6813_pladc` | 发送 poll ADC，查是否转换结束 |
| `LTC6813_pollAdc` | 阻塞等待 ADC 完成 |
| `LTC6813_rdcv` | 读回并解析全部/指定 cell 寄存器 → `ic[].cells.c_codes[]` |
| `LTC6813_clrcell` | 清除 cell 电压寄存器 |

---

### 4. GPIO / 辅助（温度等）ADC

| 函数 | 功能 |
|------|------|
| `LTC6813_adax` | 启动 GPIO / Vref2 等 AUX 转换 |
| `LTC6813_adaxd` | AUX 冗余转换 |
| `LTC6813_rdaux` | 读回 AUX → `ic[].aux.a_codes[]`（GPIO1–9） |
| `LTC6813_clraux` | 清除 AUX 寄存器 |

### 5. 状态寄存器 ADC

| 函数 | 功能 |
|------|------|
| `LTC6813_adstat` | 启动 STAT 转换（SOC、内部温度、模拟/数字电源等） |
| `LTC6813_adstatd` | STAT 冗余转换 |
| `LTC6813_rdstat` | 读回 STAT → `ic[].stat` |
| `LTC6813_clrstat` | 清除 STAT 寄存器 |

---

### 6. 被动均衡 / 放电控制

| 函数 | 功能 |
|------|------|
| `LTC6813_set_discharge` | 置位某节放电（写软件镜像 DCC） |
| `LTC6813_clear_discharge` | 清除所有放电位 |
| `LTC6813_set_cfgr_dis` / `set_cfgrb_dcc_b` | 配置层设置 DCC |
| `LTC6813_wrcfg` / `wrcfgb` | 把放电配置下发到芯片 |
| `LTC6813_wrpwm` / `rdpwm` | PWM 寄存器读写（占空比均衡） |
| `LTC6813_wrpsb` / `rdpsb` | PWM/S 控制组合寄存器 B |
| `LTC6813_wrsctrl` / `rdsctrl` | S 控制寄存器 |
| `LTC6813_stsctrl` | 启动 S 控制脉冲通信 |
| `LTC6813_clrsctrl` | 清除 S 控制寄存器 |
| `LTC6813_mute` / `unmute` | 静音/取消静音（暂停/恢复放电切换噪声相关） |

---

### 7. 断线检测（Open Wire）

| 函数 | 功能 |
|------|------|
| `LTC6813_adow` | 启动电芯开路检测转换（上拉/下拉电流） |
| `LTC6813_axow` | 启动 GPIO 开路检测转换 |
| `LTC6813_run_openwire_single` | 电芯单点断线算法 → `system_open_wire`（一路） |
| `LTC6813_run_openwire_multi` | 电芯多点/相邻断线算法（完整列表，移植版需自行保存结果） |
| `LTC6813_run_gpio_openwire` | GPIO（温度线）断线算法 |

### 9. 对外通信口（COMM）

## 三、常用业务与函数对应

| 业务目标 | 典型调用链 |
|----------|------------|
| 上电初始化 | `bms_hardware_init` → `init_reg_limits` → `init_cfg/cfgb` → `set_cfgr/set_cfgrb` → `wakeup_sleep` → `wrcfg/wrcfgb` |
| 采电芯电压 | `wakeup_*` → `adcv` → `pollAdc` → `rdcv` |
| 采温度(GPIO) | 配置 GPIO 为模拟 → `adax` → `pollAdc` → `rdaux` |
| 被动均衡 | `set_discharge` / `set_cfgr_dis` → `wrcfg`（或 PWM 相关） |
| 电芯断线巡检 | `run_openwire_single`；异常后再 `run_openwire_multi` |
| 温度线断线 | `run_gpio_openwire` |
| 上电自检 | `run_cell_adc_st` / `run_adc_overlap` / `run_adc_redundancy_st` |

---

## 四、数据落在哪里

| 数据 | 存放位置 |
|------|----------|
| 电芯电压 | `ic[i].cells.c_codes[0..17]`（约 100 µV/LSB） |
| GPIO/温度 ADC | `ic[i].aux.a_codes[0..8]` |
| 状态量 | `ic[i].stat.*` |
| 配置镜像 | `ic[i].config` / `configb` 的 `tx_data`/`rx_data` |
| 单点断线结果 | `ic[i].system_open_wire` |

---

## 五、库不直接提供的（需应用层自己做）

- SOC / SOH 估算、电流积分（需外部电流传感器）  
- 绝缘检测、接触器控制、故障状态机  
- 温度 °C 换算（需 NTC 分压公式 / 查表）  
- CAN 上报、均衡策略决策  
- `run_openwire_multi` 结果持久化（当前移植未写回结构体）
